<details>
<summary><b>More detail on each device</b></summary>
<br/>

**LearnQuest.ai.** JWT authentication with role-based access. Code runs in a sandbox via Judge0 and the Monaco editor across 10+ languages. AI proctoring covers face detection, gaze tracking and phone detection. Indexed queries and a CI/CD pipeline.

**SonicRail.ai.** Trained on 10,000+ synthetic distributed-acoustic-sensing samples. A Flask API feeds a React dashboard with live monitoring and alert streaming.

**Adaptive Reading Companion.** 100% local inference, so no data leaves the device. Published as a Chrome extension.

**AegisNet.ai.** Weighted routing across multiple AI providers, with observability through OpenTelemetry and Prometheus.

**AIPracticeHub.ai.** A full-stack coding platform. JWT and RBAC, automated code evaluation through Judge0, an optimised MySQL schema, an admin dashboard and Docker Compose deployment.
